# ElleHacks EchoLight
EchoLight is an accessibility-focused tool that turns critical ambient sounds into visual alerts, helping deaf and hard-of-hearing users gain awareness of their environment. The app listens for specific sounds, like emergency sirens or smoke alarms, and triggers customizable visual signals on a web interface, such as color flashes or icons.  This project demonstrates a proof-of-concept MVP for real-time sound-to-visual notifications, focusing on accessibility, user-centered design, and ease of use. Built with Python for audio detection, Flask for the backend, and a simple web frontend, EchoLight is designed for rapid hackathon development and clear demonstrations of impact.
